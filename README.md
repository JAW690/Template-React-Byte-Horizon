# ByteHorizon

ByteHorizon is a responsive website for a hosting company. It includes information about the company's services, pricing, background, and contact details.

## Pages

- Home
- Services
- Pricing
- About Us
- Contact

## Built With

- React and Vite
- React Router
- React Bootstrap and Sass

## Getting Started

Run these commands from the repository folder:

```bash
cd vite-project
npm install
npm run dev
```

Vite will show a local URL where you can view the site.

## Other Commands

Run these from `vite-project`:

```bash
npm run build
npm run lint
```
